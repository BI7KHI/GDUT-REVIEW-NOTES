## 说明

本目录下存放先D实践的相关文件。包含**Solidworks建模和仿真文件，AutoCAD设计文件，以及用于激光切割的DXF文件**，可复用于机电工程学院的满血金工实习
由@Xuanna024创建，完成了作业的提交，下方的机械结构可以复用用于其它作品，主要由激光切割完成
上方由3D答应制作用于~~无意义的~~展示
> Solidworks版本为2023，旧版本Solidworks可能无法打开部分文件

## 课程概述

先D课程安排由激光加工和3D打印的教学，大作业需要学生综合利用两种加工方式进行一个艺术摆件的加工，需要有创意性、可动性和结构合理性，需要机械结构的建模
~~如果遇到队友不会建模，你会体会到类似比赛时队友全部跑路的死感~~
3D打印材料为ABS默认白色，激光切割和雕刻材料为椴木板
提供减速电机(TMOTOR 5V)作为动力来源，M3螺丝用于辅助固定
